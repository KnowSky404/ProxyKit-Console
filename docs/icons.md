# Resource icons

Icons are local SVG assets served from `/icons/`, selected by the optional, validated catalog `icon` ID. They are display identifiers, not endorsements or a claim that a resource is an official integration. No third-party image requests, tracking URLs, embedded scripts or remote SVG rendering are used. Missing images fall back to the shared file icon.

YouTube, Binance, Telegram, WeChat and Wise paths are from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/55f4511de43564fc92b069635ad4f3468f4e73e5/icons), pinned at `55f4511de43564fc92b069635ad4f3468f4e73e5`. Their paths are unchanged, placed inside colored square frames. Simple Icons is distributed under [CC0](../public/icons/LICENSE.simple-icons.md); trademarks remain with their owners.

SideStore's overlapping-square identifier, Bitget Wallet's angular identifier, and Bybit/UR typographic identifiers are Console-authored vector treatments. They are not fetched upstream app artwork or verified official logos. All assets are small, inert files reviewed with the source code. A new resource without a reviewed mapping uses the file fallback rather than a guessed brand.
