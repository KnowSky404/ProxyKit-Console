# Roadmap

## V1：Public 资源浏览与复制（本次实现）

真实 Public catalog 的可重复同步与校验；三平台分类搜索；规则/插件/脚本文本预览及内容/URL 复制；SRS 仅下载/复制 URL；用户输入策略的常用片段；浅深色与移动端；Provider 抽象；Worker/API/静态资源构建；质量检查、CI、部署文档。

限制：目录是 Git 快照、需维护者同步发布；QX rewrites/scripts 暂无内容。预览最多 128 KiB，二进制不预览，无语法高亮/行号。原始 URL 跟随 main；预览固定 revision。真机导入、真实业务连通性及 Cloudflare 生产环境待验证。本次不部署。

## V2：Private 安全浏览与认证（规划）

确定 Web 身份提供者/session/CSRF/逐用户资源授权；与 Gateway 共同定版 Console 目录及用户主体协议；实现固定来源服务认证；设计可审计的设备 token 创建/撤销或用户临时手输流程。不可恢复 DEVICE_AUTH 摘要。先完成身份威胁模型和权限测试，再开放私人目录。

## V3：多 Gateway 接入与切换（规划）

服务端受控 registry、版本/能力协商、获授权来源列表、统一 Provider、故障隔离和切换。当前 UI 入口仅为禁用的规划项，不存在 Gateway 注册/连通性检查或已连接假数据。

## V4：体验增强与可靠性（规划）

在实际需求后考虑增量目录更新、上游健康检查、行号/惰性高亮、更多浏览器与辅助技术验收。根据观测再决定缓存与性能优化，不预建数据库或后台平台。

下一轮优先：1）在真实 Loon/QX/sing-box 主配置中验收片段；2）独立评审 V2 Web 身份与 Gateway 用户授权协议；3）确定目录更新频率及自动提 PR 的维护策略。
